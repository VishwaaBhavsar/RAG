# Compliance Checklist — GDPR + CCPA + Privacy Policy + T&C

## Pages
- [ ] `/privacy-policy` — all required sections present
- [ ] `/terms` — acceptable use, liability, governing law
- [ ] `/do-not-sell` — CCPA opt-out functional
- [ ] Footer links to all three on every page

## GDPR — Cookie Consent
- [ ] Banner shown before any non-essential scripts load
- [ ] Accept All + Reject All buttons
- [ ] Consent stored; banner not re-shown after choice
- [ ] Analytics/marketing scripts only load after acceptance

## CCPA — Do Not Sell
- [ ] "Do Not Sell My Info" link in footer of every page
- [ ] Opt-out stored and respected
- [ ] GPC browser signal honoured automatically
- [ ] Analytics skipped if opted out

## Privacy Policy Content
- [ ] Data types collected
- [ ] Purpose + legal basis for each activity
- [ ] Third-party sharing disclosed
- [ ] Retention periods documented
- [ ] GDPR user rights (access, erasure, rectification, portability, objection)
- [ ] CCPA section: categories, sold/not sold, opt-out link, non-discrimination statement

## Terms & Conditions Content
- [ ] Acceptable use policy
- [ ] Intellectual property statement
- [ ] Limitation of liability
- [ ] Governing law + jurisdiction (no blanks)
- [ ] How changes are communicated

## Forms
- [ ] Consent checkbox on every form — unchecked by default
- [ ] Checkbox label links to `/privacy-policy`
- [ ] Submission blocked without consent

## Security
- [ ] HTTPS / TLS on all pages
- [ ] PII encrypted at rest
- [ ] Access controls (need-to-know)
- [ ] Audit logging enabled

## GDPR — Data Subject Rights
- [ ] DSAR process: access, erasure, portability, rectification
- [ ] 30-day response SLA

## GDPR — Breach Response
- [ ] 72-hour authority notification process
- [ ] Individual notification for high/critical severity
- [ ] Breach timeline documentation

## Best Practices
| Do | Don't |
|----|-------|
| Collect minimum data for stated purpose | Pre-check consent boxes |
| Encrypt PII at rest and in transit | Load tracking before consent |
| Enforce retention periods | Leave jurisdiction blank |
| Honour GPC signals | Ignore DSARs (30-day rule) |
| Run regular compliance audits | Transfer data outside EEA without SCCs |
